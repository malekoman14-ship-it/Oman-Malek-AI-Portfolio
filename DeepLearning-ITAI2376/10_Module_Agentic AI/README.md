Overview:

This module explores Agentic AI and explains how modern AI agents differ from traditional AI models by
operating in a continuous loop of perception, reasoning, action, and observation. It covers the 
evolution of AI agents from rule-based systems to modern LLM-powered agents and introduces important
reasoning patterns such as Chain of Thought (CoT), ReAct, Reflection, Tree of Thought, Graph of Thought,
and Plan-and-Execute. The module also explains memory architectures, Retrieval-Augmented Generation 
(RAG), vector databases, tool calling, and modern frameworks like LangChain, LangGraph, CrewAI, AutoGen,
and LlamaIndex. Overall, it provides a complete foundation for designing intelligent AI agents capable
of reasoning, planning, tool usage, memory management, and multi-step problem solving in real-world 
applications.
