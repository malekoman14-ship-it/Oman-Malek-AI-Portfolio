This module introduces the fundamentals of deep learning in a simple and practical way. It explains 
how artificial intelligence, machine learning, and deep learning are connected, and how neural 
networks learn patterns from data. Key concepts such as activation functions, backpropagation, and 
model training are covered clearly. The course also highlights real-world applications, helping build
a strong foundation for understanding and applying deep learning in modern AI systems.

This assignment compares two AI-powered coding tools, GitHub Copilot and TabNine, focusing on their 
features, strengths, and real-world use cases. It explains how Copilot acts as an advanced AI pair 
programmer with strong contextual understanding, while TabNine emphasizes privacy, speed, and 
on-device processing. The document highlights their differences in usability, performance, and 
security. Overall, it shows how the choice between these tools depends on whether the priority is 
faster development or stronger data control.
