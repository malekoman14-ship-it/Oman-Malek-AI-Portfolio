Module 02 – Neural Networks Basics

This module provides a clear and structured introduction to how neural networks work in deep learning.
It explains core components such as neurons, layers, weights, bias, and activation functions, and 
shows how these elements work together to make predictions. The presentation also covers the full 
training process, including forward pass, loss calculation, backpropagation, and optimization.
Overall, it builds a strong conceptual foundation and connects theory with practical understanding 
for real-world AI applications.

Neural Network Zoo

This assignment explains neural network concepts using a creative and easy-to-understand “animal” 
analogy. Different models are represented as animals, such as CNNs as cheetahs for fast image 
detection and RNNs as raccoons for sequence memory. This approach makes complex ideas more engaging 
while still clearly explaining how each network works and where it is used. It also highlights the 
importance of selecting the right model depending on the type of data and problem.

Module 02 Lab – Hands-On Neural Networks

This lab focuses on practical learning by guiding the development of neural networks step by step. 
It begins with building a model from scratch using NumPy to understand the fundamentals, then moves 
to implementing models using PyTorch and TensorFlow. The lab also covers data preparation, model 
training, evaluation, and hyperparameter tuning. By experimenting with different settings and 
comparing frameworks, it helps develop strong real-world skills in building and improving AI models.
