Overview:
This repository section focuses on Natural Language Processing (NLP) and sequence modeling using
Recurrent Neural Networks (RNNs). The module explores how machines process and understand human 
language, why sequence order matters, and how deep learning models capture context and meaning from
text. Topics such as text preprocessing, word embeddings, RNNs, LSTMs, GRUs, and modern NLP 
applications are covered through both theory and practical analysis.

Module 04 Presentation – NLP & RNNs
This presentation introduces the fundamentals of NLP and explains how machines analyze and generate
human language. It explores the evolution of NLP from rule-based systems to transformers and large
language models. The module also explains how RNNs, LSTMs, and GRUs work to process sequential data
while addressing challenges like vanishing gradients and long-term dependencies. Real-world NLP 
applications such as sentiment analysis, translation, and speech recognition are also discussed. 

Assignment – Exploring Language & NLP Challenges in Arrival (2016)
This group presentation analyzes the movie *Arrival* through the lens of NLP and communication 
challenges. It connects the film’s alien language system with real-world NLP concepts such as 
ambiguity, semantics, symbolic representation, contextual understanding, and cultural interpretation.
The assignment also compares communication methods in the movie to rule-based NLP, statistical NLP, 
and deep learning approaches. Overall, the project demonstrates how AI and NLP systems struggle with
meaning, context, and non-linear language structures. 

NLP Analysis Report – Arrival Case Study
This report provides a deeper written analysis of communication and language processing challenges 
shown in *Arrival*. It explains how the Heptapod language reflects real NLP difficulties such as 
ambiguity, context understanding, idioms, and cultural interpretation. The report also compares the 
movie’s communication process with rule-based NLP, statistical learning, and multimodal AI systems. 
By linking cinematic storytelling with AI concepts, the report highlights the importance of advanced 
NLP systems in solving complex language and translation problems.
