Overview:
This module explores CNNs, which are specially designed for image-based tasks. It explains how CNNs
overcome the limitations of traditional neural networks by preserving spatial features and reducing
complexity. It also covers the evolution of important architectures such as LeNet, AlexNet, VGG, and
ResNet, showing how deep learning has advanced over time.

Assignment:
This project explains gradient descent using simple language and real-life analogies. It demonstrates
how models learn by reducing errors step by step and highlights the importance of learning rate. The
goal was to make a complex concept easy to understand for beginners.

Lab:
This hands-on project applies CNN concepts to a real image classification problem. It involves building
a CNN model using TensorFlow/Keras, preprocessing image data, and improving performance using techniques
like data augmentation and transfer learning. This project demonstrates practical implementation skills
in computer vision.
